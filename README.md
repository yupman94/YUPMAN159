   streamlit run app.py
   ```

> 주의: 실제 데이터 파일(`import_materials.csv`)과 첨부 파일 폴더(`attachments/`)는 보안을 위해 깃허브에 업로드되지 않도록 설정되어 있습니다. 프로그램을 처음 실행하면 빈 데이터로 시작하게 되며, 웹에서 내역을 추가하거나 대량 업로드 시 로컬에 자동으로 생성됩니다.
